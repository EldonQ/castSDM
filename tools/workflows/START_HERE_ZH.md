# castSDM 到底回答什么

**核心科学问题：环境变化会使哪些地点的预测栖息地变好或变差，哪些变化因子参与了这种响应？**

核心定位：物种栖息地变化的环境驱动解释与空间归因。
输入是已有SDM模型、预测函数、训练环境参考，以及对齐的当前/未来环境。
拟合可以用成熟SDM工具完成。castSDM统一计算并显示这些空间对比：

- 总变化：完整未来预测减去当前预测。
- 因子变化：只把一个因子换成该地点的实际未来值，其余保持当前值。
- 因子保留对比：完整未来与“该因子保持当前值”的未来相比。
- 同时显示训练范围与模型分歧；逐因子对比不保证相加等于总变化。

已有工具也能通过预测循环完成这些计算。castSDM的独立价值应是减少空间对齐、
固定比较目标、大栅格执行与论文结果组织的负担。现有证据支持实现一致与部分场景的优势，
尚不支持“普遍优于其他工具”或“识别生态因果效应”。

## 阅读结果只需要四个入口

| 图 | 读完应知道什么 |
|---|---|
| 1 模型评价 | 背景与空间分组是什么，实际评价几折，预测表现是否稳定 |
| 2 栖息地变化 | 当前/未来哪里变，总变化及各情景面积怎样变化 |
| 3 环境驱动 | 实际变化的因子在什么地点带来什么预测响应 |
| 4 范围与分歧 | 哪些解释依赖超出训练范围或模型选择 |

图件使用包内绘图与原有地图资产。完整栅格、情景、逐折评价和来源仍保留，
可选诊断不再填满默认报告。地图像元不是实验重复，模型间SD不是采样置信区间。
