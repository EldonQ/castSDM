# 栅格执行瘦身与缺陷修复

日期：2026-10-19。起点为 `f5cbb7d`（castSDM 0.20.0），保留当前统一流程、API、
`inst`地图资产、历史案例和模拟证据。此次合并执行责任，没有增加科学诊断模块。
包内R源码由12,449行降到12,282行，净减少167行；验收以缺陷修复和移除全幅
内存累积为主。测试与审查证据另行增加，不计入包内源码瘦身量。

| 优先级 | 位置与成因 | 修改及影响 |
|---|---|---|
| P1 | ensemble-raster.R 用 complete.cases，Inf 可进入预测；掩膜错位/读失败后无掩膜继续 | 统一有限值筛选；单层、同网格、有限且非零掩膜；错误停止。0掩膜格由旧版“纳入”改为“排除”，需用户显式对齐掩膜 |
| P1 | predict-tiled.R 将名为x/y的预测变量改成坐标，且吞掉预测异常 | 按fit声明变量读取；错误停止，不再发布全缺失结果来掩盖失败 |
| P1 | 切片缓存只用均值/极值和底层模型对象 | 输入内容、完整模型配置、回调静态依赖和预测入口定义参与身份；输出receipt及切片摘要验证。像元排列/回调改变会拒绝旧输出 |
| P1 | utils.R 写出失败后复制到最终路径，破坏中断保护 | 完整关闭的临时文件经rename发布；已有文件先移到备份，失败恢复。禁止copy覆盖最终路径 |
| P2 | ensemble-raster.R、effect-products.R、predict-tiled.R保留全幅输出向量 | 共用raster-io.R；逐块写出。效应均值在线累积；切片按行带拼接，内存随行带而非整个网格增长 |
| P2 | .cast_thin_points用-Inf排序未知年，使其优先；cast_thin对唯一有效行用sample(integer) | 未知年最后；并使用sample.int抽样索引，唯一有效行保留；不把年代当坐标准确性证据 |

常规集成仍按每像元有限模型重新归一化；配对归因仍冻结模型与权重。
这是有意保留的不同估计契约，不能把统一I/O当成改变科学定义的理由。
效应地图使用FLT8S存储以保留表/栅格一致；已有filename默认报错，不再算出新表
却跳过已有文件。缺失AOA诊断保留NA，不伪装为范围外的0。

验证包含实际外部预测回调和故障注入：掩膜错位/读失败、Inf、切片预测中断及恢复、
像元排列变化、回调变化、可读但被修改的缓存、覆盖失败恢复、年份缺失与唯一有效行。
新增回归文件是 `tests/testthat/test-raster-contracts.R`，并运行完整短R check。

24万像元、2模型、同输入的对照：HSS、SD、binary、MESS、6层单因子图、2模型
切片预测、18层配对归因共8项对照，最大绝对差均为0；效应与归因summary也一致。
使用的旧入口源码来自f5cbb7d，底层预测引擎相同，只比较I/O实现。

Rprofmem最大单次R分配：集成1,920,048→76,848字节，效应图→384,048字节，
切片→128,232字节。这不是进程峰值；累计分配在集成略升，不能宣传所有内存指标下降。
单次计时集成/效应略慢、切片较快，样本不足以作通用速度结论。

225万像元、2模型、有限输入、2 MB块预算、无MESS的独立进程观测：Windows实际
R进程每100 ms采样，最大工作集旧版311.46 MiB、新版238.41 MiB（约23.5%下降）。
只重复一次，可能漏过短峰值；这不是大型真实模型/跨工具通用优势证据。
同一观测的运行窗口约12.1→29.1秒，包含R进程启动；不能将减少工作集写成速度优势。
PrivateMemorySize不当作驻留内存；模型、terra/GDAL工作区仍在块预算以外。

界限：单文件替换可恢复，但多个输出不构成事务；进程被强制结束时可能留下可恢复
备份。集成的旧file.exists跳过逻辑仍缺完整身份receipt，尚须单独迁移。
回调身份只检查静态依赖；外部文件、动态get、网络/RNG状态应由调用者固定，不能
声称自动捕获任意隐藏状态。块宽仍是整个栅格宽度，极宽网格要谨慎设定tile高度。
第三方引擎版本改变也应使用新目录重新预测；缓存不是跨软件环境的可复现性保证。

工程证据见 `core_method_validation/raster_streaming_evidence_20261019`。
历史 `legacy_contract_audit` 是旧缺陷证据；06脚本现在向新目录验证修复，不覆盖历史。
此前Schizopygopsis全案例及120组模拟没有用新版重新运行，保留原始来源与结论边界。
