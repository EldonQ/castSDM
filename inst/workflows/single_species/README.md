# CHELSA 裂腹鱼亚科工作流

唯一维护的源码位于 `cast/inst/workflows/single_species`。本目录是部署副本。
`Schizothoracinae` 是亚科级历史文献记录，不代表单一生物学物种。

## 从界面运行

```r
source("E:/Package/castSDM_workflows/single_species/05_SHINY.R", encoding = "UTF-8")
```

打开“开始”，确认环境目录、记录文件、分析域及工作目录，点击“检查数据”，再点击“运行完整分析”。
检查数据只建立真实文件索引、检查来源、覆盖率、栅格几何和必要字段；不会准备背景、拟合或预测。
完整分析在独立 R 进程运行，可查看日志、停止任务。参数改动不会自动重跑模型。
默认保留 RF、MaxEnt、GAM、训练侧筛选、嵌套空间 CV、独立空间留出评价和全数据重拟合。
结果完成后自动打开地图；环境响应页计算实际情景的单因子响应、背景依赖及模型同向性，支持原生网格查询与导出。
“结果”页浏览全部已生成正式图件，下载完整案例或当前探索及界面复现脚本。

## 脚本入口

```r
source("E:/Package/castSDM_workflows/single_species/00_RUN_ALL.R", encoding = "UTF-8")
```

默认新目录：`output/cast032_chelsa_ensmean/Schizothoracinae`。
当前气候源更换后必须重新筛选、训练与验证；不迁移旧 CNClim 模型。
科学配置不同而运行目录相同会明确停止。请使用新工作目录，或脚本设置新的 `CAST_RUN_ID`。
界面设置保存在 `workflow_settings.rds`；从脚本启动也会使用这些设置。
需要回到文件内默认配置时，可先移走该设置文件。外部环境变量仍可覆盖数据和输出位置。

```r
Sys.setenv(CAST_DRY_RUN = "1")
source("E:/Package/castSDM_workflows/single_species/00_RUN_ALL.R", encoding = "UTF-8")
Sys.unsetenv("CAST_DRY_RUN")
```

索引自动检查来源路径、文件大小、修改时间、索引脚本及索引输出哈希；有变化时重建。
不修改环境数据。缺失值保留为 NoData，不用零填充。
预处理及模型缓存使用内容哈希，首次建立完整哈希会读取大量源文件。

## 解释与输出

采用一个变化组 `groups = list(climate = ...)`，直接比较当前与未来；不输出虚构的土地利用效应或交互分解。
保留原有中国地图、南海插图、配色及 PNG/PDF 导出。
导出所有有实际输入支撑的验证、当前/未来/变化、各引擎连续预测、范围变化、阈值敏感性、响应曲线、
驱动因子、支持域、模型分歧、MESS、AOA 和全部未来情景图件。
不适用或缺少输入的图件会记录原因，不伪造结果。纯气候案例不产生两组因子的交互分解图。

模型使用存在记录和抽样背景；背景不是实测缺失。历史记录与基准气候的时间不匹配会单独记录，
空间留出不等同于时间或独立外部验证。适宜度响应不是已识别的生态因果效应或真实占据概率。
单因子响应只改变指定预测变量；派生指标可能相互约束，不能直接解释为可实施的独立干预。
边际范围支持、MESS 与 AOA 是不同诊断，不混称“可信度”。

已有完整结果可用 `04_REPLOT.R <case-directory>` 重新渲染；首次完整图集需要计算缓存的诊断数据。
仅重绘使用既有图件数据，不重拟合。Shiny 打开本身不会执行完整分析。


出图会依次完成基础诊断、已有地图、响应曲线、因子地图和 MESS；前面已完成的图可以先查看。
总体响应默认用成熟的 ALE（iml），原有 PDP 可在配置中设 figure_response_method = "pdp"。
原有中国底图、南海插图、PNG/PDF 布局和全部图集仍保留。
单独重绘可设置 CAST_FIGURES 为 basic、maps、responses、drivers 或 novelty；默认 all。
因子地图的栅格批次有可核验检查点，中断后使用同一输入和输出路径可复用已完成批次。
空间分块从真实栅格自动传递 CRS，估计失败会明确停止；不再混用另一种分块。
0.32 的新科学配置不接续旧训练；已有 0.31 冻结模型仍可用 04_REPLOT.R 出图，不必为出图重训。
