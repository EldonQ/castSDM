# CHELSA 裂腹鱼亚科工作流

本例明确为**裂腹鱼亚科的河流局地分析**：保留原河网条件和记录周边 10 km 范围，不代表整个亚科的完整河湖分布。域外空白没有预测；适宜网格覆盖面积不是实际河道水域面积。spatial_output_qc.csv 记录原生预测范围，figures/source_data/display_coverage.csv 记录显示网格对原生足迹的保留情况。

显示副本使用有效原生像元的重叠面积均值，类别使用众数，支持标记使用最小值、外推标记使用最大值；原生预测不变。主效应图在同一支持域比较各驱动，全域 D_ 图集和原始表仍保留。

SchiSOFT 官方原始记录可放在 occurrence_file 同目录的 SchiSOFT_occurrence_records.csv。工作流匹配 ID、学名和坐标后恢复 sampledDate、remarksOfSampledDate、sourceType，保留简化表原有 year，不伪造日期。明确报告的采样年用于训练侧参考年，包括单一日期或完全位于同一日历年的区间；跨年区间和来源日期替代值只作记录，不变成精确采样年。sampling_date_quality.csv 和 excluded_records_by_taxon.csv 保留质控依据。0.1 度网格坐标仅提示可能精度问题，不自动删除或移动。

原始数据：[SchiSOFT v1](https://doi.org/10.6084/m9.figshare.24638538.v1)，CC BY 4.0；occurrence_records 文件下载 https://ndownloader.figshare.com/files/44560421 ，发布 MD5 为 7bbc7f681dfe98f6810f5db19dc24ee7。未提供原始元数据时保留原有年份语义，不推断真实采样日期。

0.38 在案例入口排除已核实的 GLU 全局锚点斑块近似指标，排除原因写入输入清单；不补零。其他有效土地利用指标照常参与 VIF，未规定变量数量。需重新准备数据、拟合和验证。

当前 GAM 分项贡献跨未来情景复用，预测仍采用常规、分批稳定的路径。逐模型响应见 comparison/tables/model_summary.csv 和 figures/source_data/environmental_driver_by_model.csv；Shiny 的逐模型表使用同批抽取位置，不代表面积。共有当前基线地图各绘一幅，未来情景及其他图件照常保留。

0.38 从头运行写入 `output/cast038_chelsa_ensmean`。保留简单 VIF 和模型拟合规则；GAM 统一采用分批稳定的常规预测，因此必须重新计算验证分数和阈值。
当前有效环境数据按块缓存一次，供各情景复用。读取失败会重开同一数据块一次，持续失败则记录情景、变量、文件和行号。
比较未完成时不生成完成标记；已成功的情景缓存保留。查看 `comparison/tables/scenario_status.csv`、`comparison/progress` 和 `comparison/failures`。
同配置重跑会校验并复用成功情景。旧格式缓存失效，不把旧结果改名为0.38。
`support_scope.csv` 区分变化因子和静态背景的边际范围支持；`gam_concurvity.csv` 报告保存GAM的响应替代性。两者都不证明因果效应。

全部响应曲线保留为 `R_` 分页图集，每页最多12个面板；主图展示本次情景实际变化的因子。分页不改变拟合变量数量。
`workflow_timings.csv`、`figures/phase_timings.csv` 与 `comparison/tables/events.csv` 分别记录工作流、图件阶段及当前数据块准备耗时。
`temporal_layer_matching.csv` 明确标记没有过去时间片而保留较晚来源年份的指标；`predictor_pool_summary.csv` 记录各类指标的保留数量。缺失值不自动填零，指标类别和 VIF 也不等于生态重要性。

默认流程：输入质控 → 训练折内 VIF≤10 → RF/MaxEnt/GAM → 空间验证 → CHELSA 气候情景 → 环境响应地图。
不规定变量数量；MaxEnt 使用标准 lq 特征，GAM 使用 bam。
默认 `predictor_missing="complete_cases"` 保留合格指标并使用完整样本，逐项记录缺失造成的记录损失。可选 `"drop_predictors"` 在分割前按实际采样位置剔除不完整指标、保留位置；该严格选项可能因少数缺值删除很多指标，不作为默认。两者都不插补；内部验证以输入质控为条件，不是独立外部验证。
详情写入准备目录的 `predictor_missing_qc.csv`。
界面高级设置可修改 VIF 阈值和缺失策略；假设改变处显示实际训练范围，不自动生成干预幅度。
模型没有变化因子时保留当前预测并明确标注，跳过无效因子归因。

唯一维护的源码位于 `cast/inst/workflows/single_species`。本目录是部署副本。
`Schizothoracinae` 是亚科级历史文献记录，不代表单一生物学物种。

## 从界面运行

```r
source("E:/Package/castSDM_workflows/single_species/05_SHINY.R", encoding = "UTF-8")
```

打开“开始”，确认环境目录、记录文件、分析域及工作目录，点击“检查数据”，再点击“运行完整分析”。
检查数据只建立真实文件索引、检查来源、覆盖率、栅格几何和必要字段；不会准备背景、拟合或预测。
完整分析在独立 R 进程运行，可查看日志、停止任务。参数改动不会自动重跑模型。
默认保留 RF、MaxEnt、GAM、训练侧筛选、嵌套空间 CV、内部空间留出评价和全数据重拟合。
结果完成后自动打开地图；环境响应页计算实际情景的单因子响应、背景依赖及模型同向性，支持原生网格查询与导出。
“结果”页浏览全部已生成正式图件，下载完整案例或当前探索及界面复现脚本。

## 解释与输出

采用一个变化组 `groups = list(climate = ...)`，直接比较当前与未来；不输出虚构的土地利用效应或交互分解。
保留原有中国地图、南海插图、配色及 PNG/PDF 导出。
导出所有有实际输入支撑的验证、当前/未来/变化、各引擎连续预测、范围变化、阈值敏感性、响应曲线、
驱动因子、支持域、模型分歧、MESS、AOA 和全部未来情景图件。
不适用或缺少输入的图件会记录原因，不伪造结果。纯气候案例不产生两组因子的交互分解图。

模型使用存在记录和抽样背景；背景不是实测缺失。历史记录与基准气候的时间不匹配会单独记录，
空间留出不等同于时间或独立外部验证。适宜度响应不是已识别的生态因果效应或真实占据概率。
单因子响应只改变指定预测变量；派生指标可能相互约束，不能直接解释为可实施的独立干预。
边际范围支持、MESS 与 AOA 是不同诊断，不混称“可信度”。

已有完整结果可用 `04_REPLOT.R <case-directory>` 重新渲染；首次完整图集需要计算缓存的诊断数据。
仅重绘使用既有图件数据，不重拟合。Shiny 打开本身不会执行完整分析。


出图会依次完成基础诊断、已有地图、响应曲线、因子地图和 MESS；前面已完成的图可以先查看。
